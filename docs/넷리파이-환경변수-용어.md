# Netlify에서 그 설정, 뭐라고 부르나요?

## 이름(용어)

사이트 설정에 넣는 그 목록은 보통 이렇게 부릅니다.

| 한글 | 영문 (Netlify UI) |
|------|-------------------|
| **환경 변수** | **Environment variables** |

줄여서 **env**, **ENV**라고도 많이 씁니다.  
“비밀값만” 넣는 경우 사람들이 **시크릿(secret)**이라고 말하기도 하지만, Netlify 화면에서는 대개 **Environment variables** 한 메뉴 아래에 일반 설정값·API 키를 같이 둡니다.

## 한 줄로 정리

> Netlify에 넣는 건 **환경 변수(Environment variables)** 라고 부르면 됩니다.  
> 각 줄은 **변수 이름(Key)** 과 **값(Value)** 입니다.

## 자주 헷갈리는 말

- **영역(scope)** — 값 이름이 아니라 “어디 배포에 적용할지”입니다.  
  Netlify에서는 예: Production / Deploy previews / Branch deploys 같은 **배포 컨텍스트**로 나뉩니다.
- **내용** — 넣을 실제 문자열(API 키, URL 등)은 그냥 변수의 **값(Value)** 이라고 부르면 됩니다.

## 대시보드에서 찾는 위치

**Site configuration → Environment variables**  
(사이트 선택 후 설정 메뉴에서 “Environment variables” 검색해도 됩니다.)
